# Alterspace

텅 빈 페이지에서 시작해, 필요한 기능을 말하면 AI가 직접 만들어 붙여 주는 Windows 앱이에요.

## 받기

[Releases](https://github.com/ahn610/alterspace/releases/latest)에서 받아요.

- **`Alterspace-Setup-버전.exe`**: 설치형. 새 버전이 나오면 앱이 알아서 받아요.
- **`Alterspace-Portable-버전.exe`**: 설치 없이 파일 하나로 실행해요.

처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. 서명하지 않은 개인용 앱이라서 뜨는 경고예요.

이 저장소에는 설치 파일만 올라가요. 앱이 새 버전을 확인할 때 이 저장소의 Releases를 봐요.
